# Documentação

A pasta de trabalho possui somente três áreas principais: `frontend`, `backend` e `docs`. Cada aplicação mantém suas próprias dependências e configuração de publicação.

- `plan.md`: plano de produto e desenvolvimento.
- `design-system.md`: fundamentos e componentes da identidade visual.
- `references/`: bases de dados e documentos usados como fonte.
- `deliverables/`: PDFs e apresentações produzidos pelo projeto.
